# WaveDash GamePad Viewer Skin

Custom DualSense overlay for **@itsWaveDashRL**.

## Status
The working DualSense geometry and WaveDash asset hooks are installed. The custom PNG sprite assets are the next build stage.

## GamePad Viewer
Use the PS5/DualSense base at `https://gamepadviewer.com/?p=1&s=5`.
